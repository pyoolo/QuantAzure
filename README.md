# Study Material Repository

## Overview

This repository serves as a centralized archive for study materials and research resources across three main domains of financial analysis and investment management. All materials uploaded here are intended to develop a broader understanding of market dynamics, asset classes, and quantitative methodologies.

## Repository Structure

The repository is organized into three main sections, each containing research papers, projects, case studies, and reference materials:

### 📊 Section 1: Equities
Dedicated to equity market research, analysis, and investment strategies.

**Contents may include:**
- Equity research reports and case studies
- Stock valuation methodologies
- Market analysis and sector-specific research
- Historical equity performance data
- Investment thesis documentation

**Subfolders:**
```
equities/
├── research-reports/       # Detailed equity analysis and reports
├── case-studies/           # Company-specific case studies and evaluations
├── sector-analysis/        # Sector-wide research and trends
├── data-sets/              # Datasets and market data
└── templates/              # Analysis templates and frameworks
```

---

### 🏦 Section 2: Fixed Income, Credit & Commodities
Analysis and research related to fixed income securities, credit instruments, and commodity markets.

**Contents may include:**
- Bond market analysis and yield curves

- Derivatives and hedging strategies
- Fixed income portfolio management studies

**Subfolders:**
```
fixed-income-credit-commodities/
```

## File Organization Guidelines

### Naming Conventions
- Use descriptive filenames with dates when relevant: `YYYYMMDD_Topic_Description.pdf`
- Use lowercase with hyphens for folder names: `my-research-papers`
- Avoid spaces and special characters in file names
- For code files: `descriptive_name.py`, `analysis_notebook.ipynb`

### File Types Supported
- **Research Documents**: `.pdf`, `.docx`, `.xlsx`
- **Code**: `.py`, `.r`, `.ipynb`, `.json`
- **Data**: `.csv`, `.xlsx`, `.parquet`, `.json`
- **Presentations**: `.pptx`, `.pdf`

### Best Practices
1. Add a brief description or metadata file for large projects
2. Include dates for time-sensitive analysis
3. Reference sources for external data
4. Organize by date or topic consistently within each section
5. Use README files in subdirectories for complex structures
6. Include a summary of key findings or conclusions in document metadata

## Contributing Guidelines

When uploading materials to this repository:

### Quality Standards
1. **Ensure Quality**: Materials should be well-researched and properly documented
2. **Add Context**: Include brief descriptions of document purpose and relevance
3. **Organize Logically**: Place files in the most appropriate section and subdirectory
4. **Include Metadata**: Add dates, sources, and any relevant reference information
5. **Version Control**: If updating existing materials, note the version and date

### Submission Checklist
- [ ] File follows naming conventions
- [ ] File is placed in the correct section and subdirectory
- [ ] Document includes source citations where applicable
- [ ] A brief summary or description is provided
- [ ] File format is one of the supported types
- [ ] For complex submissions, include a summary document
