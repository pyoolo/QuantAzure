# Study Material - Comprehensive Learning Archive

A hierarchical organization of financial research, quantitative methods, and foundational knowledge organized by complexity and application level.

## 📚 Structure Overview

This folder is organized into **4 progressive levels** from foundational concepts to advanced applications:

---

## 1️⃣ **Folder 1: Fundamentals** (`1-Fundamentals/`)

Essential mathematical and programming foundations for quantitative finance.

### Subfolders:
- **Algorithms** - Algorithm design, complexity analysis, optimization
- **Calculus** - Differential/integral calculus, multivariable calculus
- **Data-structures** - Arrays, linked lists, trees, graphs, hash tables
- **Foundation-of-Econ** - Microeconomics, macroeconomics basics
- **Foundation-of-Finance** - Time value of money, bonds, stocks fundamentals
- **Linear-Algebra** - Matrices, eigenvalues, vector spaces
- **Probability** - Probability theory, distributions, random variables
- **Python** - Python programming, libraries (NumPy, Pandas, etc.)
- **Statistics** - Descriptive statistics, hypothesis testing, regression basics

**Best For:** Building foundational knowledge, refreshing mathematics concepts, learning programming basics

---

## 2️⃣ **Folder 2: Methods & Analysis** (`2-Methods-Analysis/`)

Analytical techniques and methodologies for financial data analysis.

### Subfolders:
- **Data-analysis** - Exploratory data analysis, data cleaning, visualization
- **Econometrics** - Econometric models, regression analysis, time series
- **ML** - Machine learning fundamentals, supervised/unsupervised learning
- **Numerical-methods** - Numerical optimization, root finding, integration
- **Optimization** - Linear programming, convex optimization, algorithms
- **Stat-Inference** - Statistical inference, confidence intervals, p-values
- **Time-series-analysis** - ARIMA, seasonality, trend analysis, forecasting

**Best For:** Learning practical analysis techniques, understanding methodologies, implementing solutions

---

## 3️⃣ **Folder 3: Financial Theory & Models** (`3-Financial-Theory/`)

Advanced financial theory and quantitative modeling frameworks.

### Subfolders:
- **Asset-pricing** - CAPM, APT, multi-factor models, risk premium
- **Derivatives** - Option pricing, Black-Scholes, Greeks, exotic derivatives
- **Factor-models** - Fama-French factors, factor risk, factor performance
- **Financial-econometrics** - Financial data analysis, volatility models
- **Mkt-microstructure** - Market structure, order books, price impact
- **Montecarlo** - Monte Carlo simulation, variance reduction, applications
- **Portfolio-theory** - Modern portfolio theory, efficient frontier, rebalancing
- **Stochastic-processes** - Brownian motion, jump processes, SDEs, Itô calculus

**Best For:** Understanding financial theory, building models, theoretical research

---

## 4️⃣ **Folder 4: Applications & Implementation** (`4-Applications-Implementation/`)

Practical implementations, real-world applications, and advanced projects.

### Subfolders:
- **Advanced-time-series** - GARCH, regime switching, advanced forecasting
- **Alternative-data** - Alternative data sources, satellite imagery, sentiment
- **Backtesting-methodology** - Strategy backtesting, performance analysis, walk-forward
- **Execution** - Execution algorithms, VWAP, TWAP, market impact
- **High-frequency-data** - HFT, order book dynamics, tick data analysis
- **ML-for-financial-data** - Deep learning, NLP, ML for trading/forecasting
- **Order-books** - Limit order book modeling, market microstructure
- **Research-projects** - Complete research projects, case studies, papers

**Best For:** Practical implementation, real-world case studies, advanced applications

---

## 📖 How to Use This Archive

### For Learning Progression:
1. **Start with Folder 1** → Build foundational knowledge
2. **Move to Folder 2** → Learn analytical techniques
3. **Study Folder 3** → Understand financial theory
4. **Apply in Folder 4** → Implement practical solutions

### For Reference:
- Use the **folder structure** as a mental model for financial knowledge
- Each folder is **self-contained** but builds on previous levels
- **Cross-reference** between folders (e.g., ML theory in Folder 2 applied in Folder 4)

### For Organization:
- **Naming Convention**: `YYYYMMDD_Topic_Description.pdf` or `.py`
- **Subfolders**: One for each topic/technique
- **Include metadata**: Source, date, difficulty level
